# FPGA Sensor Interface Library

This repository contains Verilog modules and Python scripts for FPGA-based sensor interfacing and instrumentation. It includes drivers for I2C, SPI, and USB communication, as well as utilities for data acquisition and processing.

## Repository Structure

- **HDL/**: Verilog modules for sensor drivers and communication protocols.
- **Python/**: Scripts for FPGA communication, data acquisition, and sensor control.
- **Doc/**: Documentation and analysis of sensor performance.

## Key Features

- **I2C and SPI Drivers**: Verilog modules for interfacing with sensors.
- **Python Utilities**: Scripts for initializing FPGA communication and processing sensor data.
- **Sensor Analysis**: Noise and performance metrics for various sensors.

## Target Device

- FPGA: xc7a75tfgg484-1

## Purpose

This repository serves as a resource for developing FPGA-based sensor systems, combining hardware design with software utilities.
